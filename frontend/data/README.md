# Dados de origem

Esta pasta guarda arquivos originais para preparação e rastreabilidade.

Organização: `brasil/politico/<recorte>/<ano>/original/`.

Recortes reservados: `grandes-regioes`, `ufs`, `microrregioes`, `municipios`.

Somente os GeoJSONs em `public/data/` são carregados pelo mapa. Consulte `../DEMONSTRACAO.md` para execução e conversão.
